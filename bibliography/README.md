# Bibliography data authority

The current bibliography is **slide-locked-pass-19** and contains **206 verified records: 88 research/collection/conservation entries and 118 historical primary/object entries, across 19 publication languages**.

## Current authority

Use `bibliography-manifest.json` as the machine-readable authority. It names all current row chunks (`bibliography-01.csv` through `bibliography-22.csv`) and the schema used by the public bibliography page. `bibliography.js` loads those chunks dynamically, validates the manifest counts and generates complete CSV, TSV, JSON, CSL JSON, BibTeX and RIS exports in the browser.

The bibliography is parked as a completed public/audit state. Passes 18–19 remain part of the record but do not define an active geographic search frontier.

## Legacy static CSV

`bibliography.csv` is a **predecessor partial static index** retained for compatibility and audit history. It is not the 206-row bibliography and must not be used for current totals, deduplication or comprehensive export. New code and documentation should point to the manifest/chunks or to the bibliography page exports instead.

## Admission rule

The bibliography remains slide-locked: physical microscope slides, slide-mounted preparations, dedicated preparation catalogues/series, preparation techniques materially tied to slides, surviving slide collections, preparation-centred registers, and direct slide transfers are in scope. General microscopy history, instrument history or institutional prose enters only when the material preparation/slide layer performs substantive evidentiary work.

## Quantity rule

A bibliographic record count is not an object count. Counts embedded in bibliography notes must retain their original namespace: slides, preparations, specimens, catalogue offerings, serial positions, collection totals and database records are never normalized into a common quantity without explicit source support.
