# Oxford HSM / RMS object-access request checklist v1

Updated: 2026-09-14
Status: PREFIELD CONTACT CHECKLIST / NOT AN EMAIL DRAFT

## 1. Purpose

The RMS archive routing is already specific at box level. The remaining application-readiness gap is **material-object specificity**: the SIS application will be stronger if it can name the current RMS cabinet identifier and a small number of actual nineteenth-century preparation records that can be inspected alongside the manuscripts.

Do not ask HSM for a broad collection search. The request should be bounded to the questions below.

## 2. Current RMS slide cabinet identifier

Ask HSM to confirm:

- the current museum inventory/container identifier for the single large slide cabinet on permanent loan from the Royal Microscopical Society;
- whether that identifier is the same one used in the Small Worlds database / current Collections Online;
- whether researchers can inspect the cabinet itself, selected drawers, or selected slides by prior arrangement;
- whether photography is permitted for research.

Reason:
HSM publicly states that more than three-quarters of its c.10,000 microscope slides are contained in one RMS cabinet, but the public pages currently used in this project do not expose a secure cabinet inventory number.

Do not infer or manufacture the identifier.

## 3. Diagnostic historical-catalogue → current-slide candidates

Ask whether staff can identify **2–5 current slide records** from one or more of these bounded historical catalogue groups:

- RMS MS 5 — H. M. Gwatkin mollusc slides, 1883–90;
- RMS MS 13 — microscope slides, mainly diatoms, 1860–69;
- RMS MS 18 — `Histological Catalogue`, 1892;
- RMS Archive Box 49 — Register of slides, 1897.

Useful current-data fields:
- museum/container number;
- drawer ID;
- slide ID;
- specimen ID where applicable;
- label transcription;
- maker/preparer;
- subject/taxon;
- historical number or old label number if recorded;
- image availability.

Goal:
not to request a full crosswalk, but to establish a few concrete objects around which onsite manuscript/object comparison can be organised.

## 4. Dated public-event candidates

If historical-catalogue matching is easier from named events, ask whether any current slide records can be associated with these already controlled RMS receipt/donation events:

- 12 Jan 1870 — Rev. T. H. Browne, box of twelve bone sections;
- 9 Jun 1880 — Zoological Station at Naples via A. W. Waters, twelve named preparations;
- 11 May 1881 — Mr Crisp, another Naples slide selection;
- 13 Jun 1883 — Charles Coppock, five preparations including Eozoon and pathological lung material;
- Mar 1884 — J. Norman jun., two stickleback slides.

Guard:
The public proceedings establish historical events, not current survival. Ask staff whether diagnostic current records exist; do not imply that they must.

## 5. Redmayne publication object `[1978-665]`

Ask whether the following can be produced for consultation:

**John Redmayne, *Micro-Photographs from the Diatomaceae*, RMC (STORE), Royal Microscopical Society Collection, `[1978-665]`.**

If accessible, record:
- binding and physical format;
- flyleaves;
- RMS bookplate/stamp;
- donation/presentation inscription;
- old shelf marks;
- accession/transfer labels;
- manuscript notes;
- any relation to the 65 albumen-print sequence;
- whether the object record contains non-public provenance notes.

Research test:
Can the surviving RMS Collection volume be connected securely to the same-title author donation reported in the RMS proceedings in 1877?

## 6. RMS library/collection transfer documentation

Ask whether HSM preserves or can identify:
- an RMS library transfer list;
- old RMS shelf catalogue;
- accession documentation associated with the `1978-xxx` RMS Collection library numbers;
- documentation that would connect a historical RMS library address to current `[1978-665]`.

Do not assume `[1978-665]` means the RMS acquired the work in 1978; it is a current HSM address within an RMS collection layer.

## 7. Archive boxes already known — no need to re-ask broadly

Do not send an unfocused request for `anything about slides`.

The internal archive list already supplies:
- Box 31 — ordinary/annual minutes, Jul 1868–Feb 1883;
- Box 38 — council minutes, Feb 1863–Jul 1880;
- Box 28 — council minutes, Oct 1880–Dec 1893;
- Box 41 — ledger, 1841–96;
- Box 49 — Register of slides, 1897;
- Box 103 — catalogue of microscopes/apparatus + Donations to the Collection;
- Boxes 107–110 — relevant nineteenth-century cash books.

The next correspondence should therefore focus on **object production / object identifiers / access logistics**, not repeat archive discovery already completed.

## 8. Minimum information needed before SIS submission

Ideal:
1. RMS cabinet current identifier;
2. confirmation that selected slides/cabinet can be consulted;
3. 2–5 current slide IDs suitable for comparison with a historical register/catalogue;
4. confirmation whether `[1978-665]` can be consulted;
5. photography/access conditions.

Minimum acceptable if staff cannot pre-identify slides:
1. cabinet identifier;
2. confirmation that object-level consultation can be arranged after archival identification;
3. `[1978-665]` access status.

The application can then state exactly what historical instruments/components will be inspected without pretending object identity is already known.

## 9. What not to ask

Avoid:
- asking staff to perform the full research crosswalk;
- asking them to search every RMS slide;
- asking for generic `microscopy materials`;
- asserting Naples/Coppock/Norman slides survive;
- asking for material already answered in Lee Macdonald's archive list.

Keep the staff request short, bounded and demonstrably based on substantial preliminary research.
