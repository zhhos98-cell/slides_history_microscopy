# SBB Historic profile-catalogue morphology control, 1875–1902

**Date:** 2026-09-12  
**Status:** EXTERNAL COMPARATIVE CORPUS / PROVENANCE-GATED  
**Purpose:** identify a non-Iron-Library comparison corpus for the morphology of iron-goods catalogues and profile drawings across almost exactly the same chronology as `EBA 4/14` and `EBA 4/13`, while preventing a false claim that the dossier is a continuous original railway working file.

## 0. Core finding

SBB Historic catalogue contains:

- **`VARIA_370 — Kataloge von Eisenwaren, Profilzeichnungen von verschiedenen Eisen, 1875–1902`**.

Archive-plan context:

`Archive von Privat- und Vorgängerbahnen der SBB`
→ `VARIA Einzelstücke, Kleinstzugänge, 1852–1995`
→ `VARIA_370 Kataloge von Eisenwaren, Profilzeichnungen von verschiedenen Eisen, 1875–1902`.

Catalogue context:
- https://www.sbbarchiv.ch/archivplansuche.aspx?ID=448104

The chronology is exceptionally useful because it almost exactly overlays the Iron Library sequence:

- `EBA 4/14 Profileisenalbum`, 1877–1885;
- `EBA 4/13 Profileisenalbum`, 1886–1903.

The SBB dossier is therefore a potentially high-value **external morphology control** for what industrial profile drawings/catalogues looked like when preserved outside the Schinz & Bär archive.

---

## 1. Critical provenance warning

Do **not** call `VARIA_370` a coherent original NOB / Gotthardbahn / SBB user file.

The parent fonds is explicitly:

- `VARIA Einzelstücke, Kleinstzugänge` — miscellaneous individual items / small accessions.

At least one exposed child record, `VARIA_370_06`, states:

- it came from a **2024 clearance of a backlog/restances wall**;
- its **previous provenance is unknown**.

Therefore the safe description is:

> **an SBB Historic-held comparative corpus of iron-goods catalogues/profile drawings, 1875–1902, with provenance requiring item-level control.**

Not:

> a railway operational profile-catalogue file used continuously by a specific predecessor railway.

Railway reception/use can only be claimed for individual units if their original provenance, annotations, filing context or associated records establish it.

## 3. Why the corpus matters to EBA 4

The Iron Library onsite problem is increasingly morphological:

> what kind of objects are the five archival `Profileisenalbum` volumes, and what operations do their drawings/pages perform?

`VARIA_370` supplies a useful independent comparative field because it can help distinguish recurring period forms such as:

- producer profile sheets;
- bound or loose product catalogues;
- copied catalogues;
- engineering-reference drawings;
- component catalogues;
- profile-number systems;
- dimensional and weight tables;
- application drawings;
- later archival aggregation.

It can therefore prevent over-reading a Schinz & Bär album feature as firm-specific when it was actually common catalogue morphology.

Conversely, if `EBA 4/14` or `/13` carries unusual manuscript interventions, pasted layers, proprietary numbering, price/order traces or reformatting absent from comparable industrial catalogues, those differences become more historically meaningful.

## 4. Comparison schema

Use the same morphology fields across Iron Library and SBB Historic controls:

`DATE / PRODUCER_OR_MERCHANT / TITLE / CARRIER_TYPE / BOUND_OR_LOOSE / ORIGINAL_OR_COPY / PAGE_OR_SHEET_SIZE / PROFILE_FAMILY / PROFILE_NUMBER / CROSS_SECTION / DIMENSIONS / WEIGHT / STATIC_VARIABLES / PRICE / MATERIAL_TERM / PROPRIETARY_OR_PATENT_MARK / APPLICATION / DRAWING_STYLE / INDEX / PAGE_ORDER / INSERTION / ANNOTATION / WEAR / FILING_MARK / PROVENANCE / RECEPTION_OR_USE_EVIDENCE`.

This schema is deliberately carrier-first. It does not presuppose standardization or publication genealogy.

## 5. Relation to the 1881 Schinz & Bär roof-profile fingerprint

The new secure 1881 public roof-profile system gives one known shape/function fingerprint:

- glass-roof profile;
- small putty groove;
- larger inner drainage groove;
- firm-specific Schinz & Bär supply;
- patented in several foreign countries;
- engineering-publication cross-section.

SBB Historic material is useful as an external test for whether similar profile-catalogue conventions—section drawing, numbering, dimensions, patent/proprietary labels, application framing—occur in other producer/reference material.

Do **not** expect or assert that the exact Schinz & Bär profile is present in `VARIA_370` unless found.

## 7. Claim ceiling

Do not assert that:

- `VARIA_370` was assembled or used historically as one dossier before archival accession;
- all items belonged to SBB or one predecessor railway in the nineteenth century;
- the 1875 start date means a surviving 1875 item has already been identified;
- `_01`–`_04` contents are known;
- catalogue retention equals engineering use;
- similarities with EBA 4 prove circulation between the firms/institutions.

A feature becomes evidence of historical reception/use only with item-level provenance, annotation, filing or related operational records.
