# PINNED APPLICATION DELTA — 1896 BÄR EDITION / REFORMAT CLOSURE

**Date:** 2026-09-12  
**Authority:** this note supersedes earlier claim ceilings **only where they treat the relation between the c.1885 Schinz & Bär public profile album and the 1896 Bär & Co. public album as wholly genealogically unproven**. It does **not** prove page-by-page or profile-number continuity. All collection-first, onsite-necessity and EBA 4 morphology controls remain in force.

## 0. Governing correction

The 1896 *Schweizerische Bauzeitung* review explicitly describes the Bär & Co. `Façoneisen-Album`, Ausgabe 1896, in relation to an earlier large profile album issued by the firm roughly ten years before and repeatedly calls the 1896 object the **new / current edition** (`neue Ausgabe`, `jetzige ... Ausgabe`) in comparison with the **earlier edition** (`frühere Ausgabe`).

The public-carrier chronology can therefore be tightened from:

`1885 PUBLIC SCHINZ & BÄR PROFIL-ALBUM`
→ `[relation open]`
→ `1896 PUBLIC BÄR & CO. FAÇONEISEN-ALBUM`

to:

**`EARLIER PUBLIC PROFILE-ALBUM REGIME c.1885`
→ `1896 REVIEWER-EXPLICIT EDITION CONTINUITY / REVISION`
→ `1896 NEW/CURRENT FAÇONEISEN-ALBUM EDITION`**.

This is a contemporaneous editorial/reviewer statement about edition relation. It does **not** yet establish identical title pages, unchanged numbering, identical profile repertoire, or direct descent of every sheet.

## 1. The important new closure is not merely bibliographic: it is page reformatting

The 1896 review says the album's profiles are accompanied by tables giving:

- weights;
- dimensions;
- moments of inertia;
- load-bearing information, including lengths up to 12 m.

It then explicitly distinguishes the current edition from the earlier one by stating that the table information is now placed **at the relevant profiles** (`jeweils bei den bezüglichen Profilen ... die ... Tabellenangaben`).

The critical historical operation is therefore:

**`PROFILE AS DRAWN/CLASSIFIED FORM`
→ `PROFILE + LOCALLY ADJACENT QUANTITATIVE ENGINEERING DATA`**.

This is a page-architecture change, not only an increase in information quantity.

The reference object is becoming more locally self-sufficient: the user can encounter shape and calculation-relevant data together rather than moving between separated representational/tabular zones.

Do not overstate this as proof of a wholly new cognitive regime. It is a directly documented editorial/design change in the catalogue.

## 2. Why this is exceptionally important for the EBA 4 onsite problem

Iron Library preserves:

- `EBA 4/14 Profileisenalbum`, 1877–1885, 3 vols;
- `EBA 4/13 Profileisenalbum`, 1886–1903, 2 vols.

The public chronology now overlaps these series as:

`EBA 4/14 (1877–1885)`
→ `PUBLIC PROFIL-ALBUM 1885`
→ `EBA 4/13 starts 1886`
→ **`1896 NEW EDITION: QUANTITATIVE TABLE DATA REBOUND TO RELEVANT PROFILE`**
→ `EBA 4/13 continues to 1903`.

This makes a very specific physical test possible:

> **Can the archival volumes show when and how quantitative profile data moved from separate tables, lists or calculation surfaces into page-local attachment to individual profile drawings?**

That question is materially sharper than asking whether `standardization` increased.

## 3. New onsite reformat fingerprint

For `EBA 4/14` and especially `EBA 4/13`, record whether each profile page carries:

`PROFILE_NUMBER / DRAWN_CROSS_SECTION / DIMENSIONS / WEIGHT / MOMENT_OF_INERTIA / LOAD_DATA / LENGTH_RANGE / TABLE_ON_SAME_PAGE / TABLE_ON_FACING_PAGE / TABLE_SEPARATE_SECTION / CROSS_REFERENCE_TO_TABLE / HANDWRITTEN_QUANT_DATA / PASTED_QUANT_DATA / REPLACEMENT_SHEET / REVISION_MARK`.

Then test the following transitions:

1. **shape only → shape + dimensions**;
2. **shape + dimensions → shape + weight**;
3. **profile section + distant summary table → profile-local table**;
4. **general table → per-profile repeated data**;
5. **proprietary profile without static data → proprietary profile with static data**;
6. **Normalprofil and proprietary profile given symmetrical vs asymmetrical quantitative treatment**.

If the physical sequence preserves these changes, the EBA 4 albums can show the material work behind the public 1896 editorial claim.

## 4. Revised profile-identity model

The new Schoch comparator showed that catalogue users could select a numbered profile by shape and dimensions and reuse it beyond the catalogue's original functional category.

The 1896 Bär review now shows a complementary operation at the producer/merchant publication side:

`PROFILE IDENTITY`
can be strengthened by binding together:

- number;
- geometry;
- dimensions;
- weight;
- moment of inertia;
- load-bearing information;
- category / application;
- Normalprofil or proprietary status.

The project can therefore ask not merely how profiles were standardized, but **how distributed attributes were recombined into one operational reference unit on the page**.

## 5. Revised claim ceiling

### Secure now

- an earlier large Bär/Schinz profile album existed roughly ten years before 1896; the independently controlled 1885 review provides a concrete match;
- the 1896 reviewer explicitly frames the 1896 album as a **new/current edition** relative to an **earlier edition**;
- the 1896 edition includes quantitative data on weight, dimensions and moments of inertia plus load information;
- the reviewer explicitly identifies **placement of those table data at the relevant profiles** as an improvement over the earlier edition;
- the 1896 album combines Normalprofile and Bär proprietary profiles and is offered to technical schools in desired quantities.

### Still open

Do **not** yet assert:

- every 1885 profile survives into 1896;
- profile numbers remain stable between editions;
- page order is continuous;
- `EBA 4/14` is the master or working copy for 1885;
- `EBA 4/13` is the master or working copy for 1896;
- the quantitative reformat first occurred exactly in 1896 rather than in an intervening unlocated edition;
- the 1885 and 1896 titles were formally numbered editions on their title pages;
- the reviewer's `frühere Ausgabe` necessarily refers only to one unique physical edition without intermediate issues.

The correct formulation is:

> **The 1896 review supplies contemporaneous evidence of an edition/revision relationship and identifies a concrete page-format change; the exact physical lineage and profile-level continuity remain to be tested.**

## 6. Application-level consequence

The strongest current operation is now a three-part versioning problem:

1. **IDENTITY** — what makes a profile stay the same across carriers/editions?
2. **REFORMAT** — which attributes are newly attached to the profile at page level?
3. **MAINTENANCE** — how are multiple copies kept current through new albums and supplement sheets?

This can be stated compactly as:

> **How did Zürich iron merchants maintain the identity of industrial profiles while repeatedly reformatting, quantifying and updating the reference systems through which those profiles were sold, calculated, taught and selected?**

## Resume point

Resume from the now-secure **edition/reformat operation**:

`1885 PUBLIC PROFILE-ALBUM`
→ **`EDITION REVISION`**
→ **`1896 PROFILE + LOCALLY ATTACHED QUANTITATIVE TABLE DATA`**
→ `1903 NEW ALBUM SET`
→ `1907 SUPPLEMENT SHEET ×12`.

The next external priority remains an extant 1885 or 1896 full album / reproduction. The next onsite priority is to test whether `EBA 4/14` and `/13` physically preserve the reformatting and version-maintenance layers described by the public record.
