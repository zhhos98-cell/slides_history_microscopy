### Critical edition correction already closed

The 1896 *Schweizerische Bauzeitung* review does **not** treat the 1896 album as wholly unrelated to the earlier large profile album. It explicitly contrasts the **current/new edition** with the **earlier edition** and identifies a specific improvement: quantitative table data are now placed **at the relevant profiles**.

Therefore edition/revision continuity is contemporaneously attested at reviewer level. What remains open is **profile-by-profile physical continuity**: numbering, page order, repertoire, title-page edition statements and any intermediate issues.

See `PINNED_APPLICATION_DELTA_1896_EDITION_REFORMAT_2026-09-12.md`.

### Newest cross-fonds correction

The 1895 Bär–GF contract is no longer an isolated adjacency. Contemporary controls now show:

- GF already operated a very large fittings/model repertoire before the contract;
- Bär was already situated in a Zürich gas/water-line article merchant category by 1893/94;
- the 1895 contract specifically concerns production and sale of `Geländerfittings` by Georg Fischer III;
- in 1896 Bär is publicly described as originator (`Urheberin`) of new railing-construction/handrail **profiles**;
- in 1896 GF publicly exhibits new railing **connectors** (`Geländer-Verbindungsstücke`) physically used on the Fischer exhibition-group railing;
- the official exhibition report immediately associates this new article with the Singen factory expansion of the previous year and a large labour force.

This is potentially a distributed identity system, **not** proof that Bär profiles and GF fittings are the same objects.

See `BAER_GF_DISTRIBUTED_PRODUCT_IDENTITY_1891_1896_2026-09-12.md`.

## 3. Strongest empirical object

The project is no longer best described as generic `standardization`.

Current three-part problem:

1. **IDENTITY** — what makes a profile remain the same object across carriers / editions?
2. **REFORMAT** — which attributes become newly attached to the profile at page level?
3. **MAINTENANCE** — how are multiple reference copies kept current through new albums / supplements?

Identity variables:

`PROFILE NUMBER ↔ SHAPE ↔ DIMENSIONS ↔ WEIGHT ↔ MOMENT OF INERTIA ↔ LOAD DATA ↔ CATEGORY ↔ PRICE/ORDER KEY ↔ PROPRIETARY/NORMAL STATUS ↔ EDITION ↔ SUPPLEMENT`.

Newest cross-organisational identity variables:

`MERCHANT PROFILE ID ↔ DRAWING ↔ CONTRACT PRODUCT TERM ↔ PRODUCER MODEL ID ↔ TOOLING/PATTERN ↔ MAKER MARK ↔ STOCK/ORDER KEY ↔ SALES RESPONSIBILITY ↔ CATALOGUE REFERENCE`.

The central question remains:

> **What made an iron profile remain the “same profile” while merchant reference systems repeatedly reformatted, quantified and updated it?**

The new falsifiable extension is:

> **When an industrial component crossed from Bär's merchant/reference system into Georg Fischer's manufacturing regime, what — if anything — made it the same identifiable product on both sides?**

## 5. New cross-fonds control: Bär ↔ Georg Fischer, 1895–96

### Secure

`GFA 1/171` records a 3 January 1895 contract between Bär & Cie and Georg Fischer III concerning production and sale of `Geländerfittings` by Georg Fischer III.

Contemporary external controls establish a real product ecology around it:

- GF advertisement, 1891: c.2,000 fitting forms/combinations in an established model-rich fittings business;
- Zürich trade directory, 1893/94: Bär listed among merchants for gas/water-line articles;
- Bär public album review, 1896: new railing-construction/handrail profiles, with Bär named as originator;
- official Swiss National Exhibition journal, 1896: new GF `Geländer-Verbindungsstücke`, actually used on the Fischer group's railing; factory-expansion statement follows directly.

### Not secure

Do not collapse:

`BÄR GELÄNDER-KONSTRUKTION / HANDLEISTEN PROFILE`
=
`GF GELÄNDERFITTING / GELÄNDER-VERBINDUNGSSTÜCK`.

The strongest operation is now to seek a **shared identifier / drawing / morphology / catalogue reference / contract annex**.

If none exists, the negative result is meaningful: the two firms may have maintained complementary component identities rather than one shared product genealogy.

## 6. Onsite physical tests for the five profile albums

For all volumes establish first:

- binding / title / imprint / date layers;
- printed vs pasted vs manuscript construction;
- stubs, removals, replacement sheets, loose inserts;
- revision and supplement marks;
- page / sheet sequence;
- changing company imprints;
- numbering / renumbering;
- proprietary vs Normalprofil layers;
- quantitative table placement;
- annotations / wear / transaction marks.

Profile-level capture:

`VOLUME / PAGE_OR_SHEET / INTERNAL_DATE / PROFILE_NUMBER / CATEGORY / SHAPE / DIMENSIONS / WEIGHT / MOMENT_OF_INERTIA / LOAD_DATA / INTENDED_USE / PROPRIETARY_MARK / NORMALPROFIL_MARK / PRICE_CODE / ORDER_REFERENCE / PRODUCER_OR_SUPPLIER / COMPANY_IMPRINT / PRINTED_PASTED_MANUSCRIPT / TABLE_LOCATION / REVISION_MARK / REPLACEMENT_SHEET / SUPPLEMENT_STATUS / CROSS_REFERENCE`.

Primary concordance tests:

1. same number + same shape + same dimensions;
2. same number + changed shape/dimensions;
3. same shape + new number;
4. same profile + changed category/use;
5. profile + separate quantitative table → profile-local table;
6. proprietary / Normalprofil coexistence or status change;
7. base album → replacement / supplement / cancellation;
8. **album identifier → price list / cash / sales / inventory identifier**;
9. **album / ledger identifier → 1895 Bär–GF contract / GF model or drawing identifier**.

The eighth test remains the strongest route to proving that catalogue identity became transaction identity. The ninth is the new high-risk/high-return route to proving interoperability between merchant and producer identity systems.
