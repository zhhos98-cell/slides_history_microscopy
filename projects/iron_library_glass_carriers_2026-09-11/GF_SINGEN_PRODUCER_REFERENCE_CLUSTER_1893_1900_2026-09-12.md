**Purpose:** define the smallest high-value Georg Fischer/Singen corpus needed to test the active EBA 4 Bär profile-identity project without expanding into the full 71 lfm `GFA 22` fonds.

## 0. Current conclusion

A genuinely symmetric producer-side identity carrier has now been located:

- **`GFA 22/1338 — Modellbuch für Temperguss`, 1895–ca.1950, 1 volume**.

The public archive description states that this volume is:

- ordered by **model number**;
- records the **whereabouts / disposition (`Verbleib`) of the model**;
- records **names, possibly customers**;
- contains model numbers **1–10553**;
- indexed under the subject terms **`Fitting :: Modelle`**;
- associated with **Singen**.

Catalogue:
- https://archives.georgfischer.com/objects/50889

This changes the Bär–GF comparison materially. The project no longer has only:

`MERCHANT PROFILE ALBUM -> 1895 CONTRACT -> GENERIC MANUFACTURER`.

It now has a potential cross-system comparison:

`BÄR PROFILE IDENTITY`
↔ `3 JAN 1895 CONTRACTUAL PRODUCT INTERFACE`
↔ **`GF MODEL IDENTITY: MODEL NO. 1–10553 + MODEL WHEREABOUTS + POSSIBLE CUSTOMER NAME`**.

The decisive question is whether the Bär contract/product family can be mapped into this producer model-number regime.

## 1. Why `GFA 22/1338` is unusually important

The active EBA 4 project asks what makes an iron profile remain the same object across album, catalogue, quantitative table, price/order record, edition and supplement.

`GFA 22/1338` creates a producer-side analogue:

> What made a cast fitting remain the same production object across model number, physical pattern/model, customer/disposition, contract, manufacture and sale?

Potential identity variables:

`GF MODEL NUMBER ↔ MODEL / PATTERN ↔ OBJECT FORM ↔ DIMENSIONS ↔ MATERIAL ↔ CUSTOMER/NAME ↔ MODEL WHEREABOUTS ↔ PRODUCT CLASS ↔ DRAWING ↔ CONTRACT REFERENCE ↔ ORDER ↔ OUTPUT`.

Do not assume all these fields occur in the volume. Only `MODEL NUMBER`, `VERBLEIB`, `NAME/POSSIBLE CUSTOMER`, `FITTING/MODEL`, and the range `1–10553` are catalogue-secure.

### Critical date warning

The catalogue assigns the volume `1895–ca.1950`, but describes its contents as `undatiert`.

Therefore:

- the **volume's archival date envelope begins 1895**;
- it is **not yet proven** that model no.1, early-number pages, or any particular entry were physically entered in 1895;
- chronological stratigraphy inside the book must be established onsite from handwriting, ink, annotations, company forms, later additions, index structure or related records.

This is a first-order source-critical task.

## 2. Fonds-level context: why this is not an isolated survivor

`GFA 22 — Werk Singen, historisches Archiv` is a 71 lfm fonds with about 1,400 description units.

The archive's own fonds history states:

- the Singen plant was built and put into operation under Georg Fischer III in **1895**;
- GFA 22 contains records from the **construction of the plant in 1894 and commencement of operations in 1895**;
- Singen was a production site for **Temperguss-Fittings for the German market**;
- many surviving folio volumes include cash/inventory books, debtor/creditor registers, wage registers and other serial records, some beginning in **1895**;
- the current class arrangement was created during the archive transfer/cataloguing in **2005/06**, so modern classification must not be mistaken for original office order.

Catalogue:
- https://archives.georgfischer.com/objects/30

### Consequence

The model book is embedded in a broader surviving factory record environment rather than floating as a later museum object. But the application should **not** treat all 71 lfm as a research corpus.

The correct operation is targeted retrieval around model identity, factory formation, goods output and printed product representation.

## 4. Why this is stronger than a generic producer context

Previously GF could have remained a contextual endpoint:

`BÄR REFERENCE SYSTEM -> CONTRACT -> GF MANUFACTURE`.

The model book changes the relation to:

`BÄR NUMBERED / DRAWN PROFILE IDENTITY`
↔ `CONTRACTUAL DEFINITION AND DIVISION OF RIGHTS/RESPONSIBILITY`
↔ `GF NUMBERED MODEL IDENTITY`
↔ `PRODUCTION / MODEL WHEREABOUTS / POSSIBLE CUSTOMER`
↔ `GOODS OUTPUT / PUBLIC PRODUCT CARRIER`.

This permits a direct comparison of **two information infrastructures that identify material forms**:

### Merchant system

`NUMBER / CROSS-SECTION / DIMENSION / WEIGHT / MOMENT OF INERTIA / CATEGORY / PRICE-ORDER KEY / EDITION / SUPPLEMENT`.

### Producer system

`MODEL NUMBER / PHYSICAL MODEL-PATTERN / VERBLEIB / POSSIBLE CUSTOMER / PRODUCT CLASS / [DRAWING-DIMENSION-ORDER fields to test]`.

The 1895 contract is then not simply evidence of a relationship. It becomes a possible **translation document between two identification regimes**.

`1896` — `GFA 1/311` Warenausgang Singen und Schaffhausen begins

`1896` — `GFA 1/650` printed/prospectus/advertising dossier begins

`1896` — Bär album review names Bär as originator of new `Geländer-Konstruktionen (siehe Handleisten)` profiles and documents the page-level reformat of quantitative data.

This is now a genuinely dense **1893–96 overlap cluster** rather than a single-contract coincidence.

## 7. Strong falsifiers

### No Bär/Geländer trace in `GFA 22/1338`

Then the model book remains a valuable producer-side comparator but does not close the contract bridge.

### Early `GFA 1/311` is aggregate only

Demote; do not spend residency time chasing output statistics that cannot crosswalk to model/profile identity.

### `GFA 1/1261` early project material is retrospective or purely administrative

Use only for factory chronology, not technical identity.

### `GFA 1/650` has no early fittings/product-number material

Drop.

### Bär profile system and GF model system use entirely separate identifiers

This is historically meaningful: the contract may coordinate responsibility/markets without creating a shared information key. The project then becomes a study of **distributed but non-interoperable identity systems**.
