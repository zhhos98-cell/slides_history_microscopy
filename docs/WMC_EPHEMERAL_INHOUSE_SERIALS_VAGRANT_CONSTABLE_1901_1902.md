## 1. Why this matters

The RSVP application explicitly proposed surveying:

> scattered, short-run, or internally circulated publications retained by Working Men's College but not readily identifiable through standard periodical catalogues.

Two such serials have now surfaced bibliographically:

- *The Vagrant* — WMC in-house journal, 1901–1902;
- *The Constable* — WMC in-house journal, 1902.

These are not merely hypothetical examples of ephemeral College print. A rare-book description gives title-level, issue-level, format and production-history information and explicitly characterizes both as Working Men's College in-house journals.

This makes them **high-priority RSVP physical-inspection targets** even if their scientific/natural-history content turns out to be limited.

## 6. Why this changes the WMC serial model

The current WMC serial ecology is no longer adequately represented as:

`1859–61/62 Magazine -> long gap -> 1890+ Journal`

A better working model now includes multiple levels:

```text
flagship institutional serials
    - Working Men's College Magazine
    - Working Men's College Journal

club / report / programme print
    - College reports, programmes, prospectuses
    - Field Club / club records and notices

ephemeral in-house serials
    - The Vagrant (1901–02; 4 issues reported)
    - The Constable (1902; 1 issue reported)

external circulation interfaces
    - Science-Gossip
    - Nature
    - peer institutional magazines / Our Contemporaries lists
```

This supports a more complex research question:

> **How many different serial forms coexisted inside WMC, what audiences did they serve, and which institutional/scientific/social functions were assigned to each?**
