## 1. National architecture

```text
People's / Working Men's Colleges
            |
            | teachers / pupils / classes
            v
local adult-science networks
            |
            +---- Mechanics' / Working Men's Institutes
            +---- natural-history societies
            +---- microscopical societies
            +---- university / extension teachers
            |
            v
microscopical practice
            |
            +---- demonstration
            +---- practical preparation
            +---- collections / cabinets
            +---- borrowing / exchange
            |
            v
microscope slides and preparations
            ^
            |
commercial + domestic mounters / dealers / exchange press
```

No vertical edge is assumed merely because two nodes share a town. Every edge should ultimately be represented by a dated person/object/transaction relation.

## 14. Relation grammar for the next stage

Only relations of this kind should enter the object graph:

```text
person --prepared--> slide
person --mounted--> slide
person --sold/exchanged--> slide
institution --purchased--> slide/set
person --donated--> slide --> institution
institution --lent--> slide --> member
teacher --used in class--> slide/preparation
teacher --taught preparation of--> slide
society --exhibited--> slide/preparation
institution --generated--> microscopical society
collection --transferred to--> later institution/museum
```

The national reconnaissance has done its job once it supplies bounded candidates for these relations. It should not expand indefinitely into a directory of every Victorian adult-education institution.
