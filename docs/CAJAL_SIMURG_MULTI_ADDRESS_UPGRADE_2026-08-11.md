# Cajal Simurg multi-address upgrade — 2026-08-11

## Result

Upgrade the Cajal Legacy from an A+ re-addressing comparator to **S-level public-metadata address history** for selected preparations. Simurg records preserve several retrieval regimes for the same surviving slide: original `Armario de Preparaciones` cabinet/tray, Gamundi and Manzano inventory numbers where present, another historical inventory number, the modern `LC` reference, a current archival signatura, and a persistent digital record.

This is stronger than a museum catalogue that merely assigns a new accession number. The present catalogue explicitly carries obsolete addresses forward.

## Mechanism

The address chain is not one number replacing another. It is a stack:

`slide + label → AP cabinet/tray → historical inventories → LC reference → archival signatura → Simurg persistent record`.

That makes Cajal a direct comparator to Cole. Cole preserves publication identity through a nineteenth-century cabinet address system; Cajal preserves institutional history by retaining successive address systems in one modern catalogue. The useful distinction is **address persistence** versus **address translation**.
