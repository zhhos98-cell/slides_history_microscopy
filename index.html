01 Project

The slide is a small object with a long institutional life.

This project starts from surviving microscope slides and the collections that hold them. It asks how preparations were made, sold, exchanged, labelled, grouped into cabinets, moved between institutions, and re-described over time. The object catalogue and the nineteenth-century text corpus remain separate evidence layers; links between them are asserted only when a source closes the relationship.

Core rule

Catalogue numbers, cabinet capacities, distributed serial ranges, database rows and surviving physical slides are different quantity namespaces.

06 Method

Evidence first; relations remain typed.

The project keeps three things apart: what a source says, what a database row describes, and what the research layer infers. Maker, owner, donor, purchaser, preparer, dealer, exhibitor and later custodian are therefore stored as different relationships even when one person or institution occupies several roles.

  1. 1
    Start from a surviving node.

    Institution, cabinet, slide set, bounded subset or individually catalogued slide.

  2. 2
    Run bounded historical queries.

    Actor, object, event, taxon and preparation language are searched in context.

  3. 3
    Inspect the actual source unit.

    Positive string hits remain routing signals until page-level context establishes the relation.

  4. 4
    Record the closure and its limits.

    Exact match, bounded family/programme correspondence, or unresolved identity.
