# Compact schema notes

The core and extension registries preserve source-level identifiers and bibliographic/document metadata needed for navigation. They do not reconstruct omitted page/article/full-text payloads. BNA query/year yield values are stored as strings because the canonical master exports them as report-table cells; consumers may cast numeric cells when aggregating.

The frozen 155 object catalogue remains a separate evidence layer and retains its own closure contract.
