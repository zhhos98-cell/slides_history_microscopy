# BNA compact publication layer

The canonical BNA master contains 9,365 article-level records. Pages does not duplicate their article payloads or OCR. The compact public layer publishes all 43 query-yield rows (`BNA_QUERY_YIELD_V4.json`) and all 71 year-yield rows (`BNA_YEAR_YIELD_V4.json`). It additionally records the existence and counts of 930 event clusters and 995 newspaper-yield rows in `BNA_META_V4.json` / `CORPUS_MANIFEST_V4.json`.

This keeps aggregate/searchable results available without turning the website into a second copy of the full newspaper corpus.
