# Maltwood's Finder — printed reference convention and hardware address, 1858–1865

Updated: 2026-09-10
Status: PRIMARY_AND_NEAR_PRIMARY_REFERENCE_CONVENTION_SECURE__ADOPTION_CAUSATION_NOT_CLAIMED
Scope: bounded address-system case. This note asks how a printed/geometric convention made a microscopical field relocatable and how microscope makers could build hardware `in conformity` with that convention. It does not open a general finder history.

## 1. Maltwood's original problem and bibliographic locator

Thomas Maltwood, `On a Finder for Registering the Position of Microscopic Objects`, *Transactions of the Microscopical Society of London* 6, pp. 59–62, is generally bibliographed to 1858; some later scientific references give 1859 for the same volume/article. Preserve the 1858/1859 publication-year variance until the original issue wrapper/title-page chronology is controlled.

The problem is explicit in the title: registering a position so that a microscopic object can be found again.

Bibliographic controls:
- Maltwood T. (1858), *Transactions of the Microscopical Society of London* 6:59–62, cited in recent diatom scholarship.
- Later references sometimes cite the same item as 1859, n.s. 6:59–62.

## 2. Beck 1865 describes the finder as a reference convention

Richard Beck's 1865 *A Treatise on the Construction, Proper Use, and Capabilities of Smith, Beck and Beck's Achromatic Microscopes* states that after discussion in the *Quarterly Journal of Microscopical Science*, the makers selected Maltwood's scheme and that it had become, in Beck's words, `a universal standard of reference`.

Beck describes:
- a glass slide 3 × 1¼ inches;
- a photographed scale occupying one square inch;
- 2,500 squares;
- each square separately numbered by `longitude and latitude`;
- the scale fixed at an exact distance from the bottom and left-hand edge of the glass;
- the finder placed against the stage ledge and a fixed stop;
- the object slide placed against the same ledge and stop;
- with the desired object in view, the object slide is replaced by the finder and the coordinate read;
- the coordinate may then be recorded on the object slide;
- later relocation reverses the procedure.

Public text:
https://www.microscopemuseum.eu/books/Richard_Beck_1865_A_treatise_on_the_construction_proper_use_and_capabilities_of_Smith_Beck_and_Beck_achromatic_microscopes.pdf

Evidence level: PRIMARY PUBLISHED TECHNICAL DESCRIPTION / SECURE for Beck's 1865 account and wording.

Evidence ceiling: `universal standard of reference` is Beck's 1865 claim as a manufacturer/author, not an independently measured adoption rate.

## 3. The coordinate is relational, not intrinsic to the object slide

Maltwood's scheme does not engrave a permanent coordinate grid onto every specimen slide. It makes the object relocatable by requiring two slides to occupy the same physical datum on the microscope stage:

`stage ledge + fixed stop → object placed in field → replace object slide with calibrated finder at same datum → read latitude/longitude square → record coordinate → reverse procedure later`.

The address therefore depends on controlled substitution. The coordinate remains useful only if the finder and the object slide are seated reproducibly against the same stage references.

This is a different address system from:
- a cabinet slot physically holding one slide;
- a museum accession number attached to one object;
- Möller's Typenplatte, where many specimens occupy fixed positions inside one preparation and an external key translates position into taxonomic name.

## 4. *Science-Gossip*, 1 November 1865 — convention enters microscope hardware

A short `Maltwood's Finder` notice in *Hardwicke's Science-Gossip* reports:

`Some makers are adding to the stage of their microscopes a scale graduated in conformity with Maltwood's Finder, whereby the use of a separate "finder" is dispensed with.`

Primary public page:
https://en.wikisource.org/wiki/Page:Hardwicke%27s_Science-Gossip_-_Volume_1.pdf/275

Evidence level: PRIMARY / SECURE for the periodical's 1865 report.

Historical action: the notice records a change in material implementation. A coordinate convention first embodied in a separate reference slide could be built into the microscope stage itself, provided the graduation remained `in conformity` with the recognized scheme.

Do not claim that *Science-Gossip* caused makers to adopt the stage scale. The page reports the adoption; it does not document the manufacturers' decision process.

## 5. Knowledge-level significance: compatibility rather than transmission

The useful historical operation is not `knowledge of Maltwood's Finder spread among microscopists`.

A stronger first-order formulation is:

- Maltwood defined a repeatable procedure for converting a field position into a numerical address;
- Beck presented the scheme as a standard reference and explained the exact geometry required for relocation;
- *Science-Gossip* reported makers altering microscope stages `in conformity` with the same scheme so that the external finder could be omitted.

The printed/geometric specification can therefore outlive one material implementation. The same reference relation may be embodied in a removable calibrated slide or in a graduated microscope stage.

That is a compatibility condition: independent hardware can participate in the same locating practice only insofar as it preserves the relevant scale/datum relation.

## 6. Relation to the slide-history address thesis

Maltwood adds a distinct form of address to the repository's existing mechanisms.

A slide label can identify the preparation as a whole, but it cannot by itself relocate one minute object inside a large field. Maltwood's procedure gives an internal field position a recoverable numerical address.

The address chain is:

`microscopic point of interest → stage position → calibrated finder square → latitude/longitude number → number recorded with/on object slide → later stage relocation`.

This is especially important for preparations containing many dispersed objects or a large surface: persistence of the glass slide does not automatically preserve practical access to the particular microscopic point that mattered.

## 7. Comparison with Möller's Typenplatte

The two systems solve different retrieval problems.

### Maltwood
- one object/field point is relocated by substituting a calibrated finder at the same stage datum;
- coordinate belongs to a relation between stage, finder, and specimen slide;
- independent microscope hardware can potentially embody a compatible graduation.

### Möller
- hundreds of diatom types are deliberately arranged in a fixed internal sequence on one slide;
- an external written key maps line and position to taxonomic identity;
- the preparation itself is manufactured as a reference collection.

Both make microscopic material addressable, but one registers an otherwise contingent field position while the other constructs the specimen order in advance.

Do not collapse them into one universal coordinate system.

## 8. Surviving-object / later-history guard

Later museum and microscopical literature preserves Maltwood finder slides and describes the same 2,500-square latitude/longitude system. These later witnesses are useful for survival and afterlife, but the mechanism above is already secure from the 1865 technical description and periodical notice.

Do not infer from later ubiquity that every 1860s microscope or slide used Maltwood coordinates.
