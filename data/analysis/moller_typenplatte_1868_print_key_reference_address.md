# Möller's `Diatomaceen Typen Platte` — 1868 print/key reference address

Updated: 2026-09-10
Status: PRIMARY_1868_REFERENCE_ARCHITECTURE_SECURE__LATER_COLLECTION_BRIDGE_SEPARATE
Scope: bounded early witness to J. D. Möller's arranged diatom type slide. This file supplements the existing La Plata Möller / Tempère & Peragallo series analysis; it does not reopen general Möller discovery.

## 1. 1868 *Science-Gossip* witness

*Hardwicke's Science-Gossip* 4 (1 August 1868), printed p. 188, reports an object exhibited at the Quekett Microscopical Club meeting of 26 June: Möller's `Diatomaceen Typen Platte`, sent from Prussia through Herr Weissflog of Schoenebeck.

The notice describes:
- an ordinary 3 × 1 inch glass slide;
- a central square about one-eighth inch across;
- four smaller squares;
- about 100 diatoms in each smaller square;
- specimens arranged in parallel lines and consecutive order;
- about 400 diatoms representing 370 species/types of genera and subdivisions;
- an accompanying book functioning as the `key`;
- the name of each diatom recoverable from its line and its position on that line.

Primary public text:
https://upload.wikimedia.org/wikipedia/commons/f/fe/Hardwicke%27s_science-gossip._Volume_4%2C_1868._%28IA_s457id13663190%29.pdf

Evidence level: PRIMARY / SECURE for the published 1868 description and Quekett exhibition report.

## 2. Surviving 1868 object

Harvard Collection of Historical Scientific Instruments preserves a Möller diatom-type identification test plate dated 1868, inventory 1998-1-1171. It has four groups of diatoms, is signed/dated on the glass, and carries Möller's `Diatomaceen-Typen-Platte` inscription and production number 42.

Official object record:
https://chsi.emuseum.com/objects/9917/mollers-diatomtype-identification-test-plate

Evidence level: CURRENT MUSEUM OBJECT / SECURE for survival and object inscription. Do not assume this is the same individual slide exhibited at Quekett unless provenance proves it.

## 3. The slide is a spatial reference apparatus, not merely a dense collection

The consequential feature in the 1868 notice is the relation between arrangement and key. The slide's diatoms are not only mounted together. Their order gives each type a recoverable spatial address: small-square / line / position in line. The book translates that address into a taxonomic name.

This differs from a slide whose label alone names one preparation. Identification depends on the coupled apparatus:

`arranged glass preparation ↔ stable sequence of positions ↔ external written key`.

If the written order or spatial arrangement breaks, the taxonomic reference function is impaired even if all 400 frustules remain physically present.

## 4. Contemporary and near-contemporary descriptions strengthen the reading

A Quekett account of the same 1868 exhibition, reproduced in later historical material, describes the slide as a `useful typical collection`, notes that large *Eupodiscus argus* specimens mark the beginnings of lines, and says the accompanying catalogue enters specimens in proper order so that moving the slide across the field brings each into view successively and lets it be named from the catalogue.

A James W. Queen instrument catalogue around 1870 likewise describes Möller's Typen Platte as diatoms arranged in four quadrangles, each divided into lines containing successive species.

These descriptions show that the reference effect was understood through ordered retrieval, not merely through the virtuosity of mounting many diatoms on one slide.

Evidence level: NEAR-CONTEMPORARY / SUPPORTING. Use the 1868 *Science-Gossip* page as primary authority for the first-order description in this note.

## 5. Relation to the existing La Plata Möller mechanism

The repository already controls a later survival regime in which part of Möller's Typenplatten entered Joaquín Frenguelli's reference material and then Museo de La Plata collections. The current La Plata analysis emphasizes maker/series identity surviving institutional re-addressing and later comparative scientific use.

The 1868 source adds an earlier functional layer: `Typenplatte` was already presented as an ordered taxonomic reference object whose internal spatial sequence had to remain aligned with an external key.

This allows a more precise mechanism across, but not a provenance chain between, the two controlled moments:

- 1868: one glass slide compresses hundreds of named types into a spatially ordered reference field paired with a key;
- later collection history: Möller reference preparations can survive dispersal/acquisition while retaining maker/series identity and comparative function.

Do not claim that the specific 1868 Quekett slide travelled to La Plata. No such provenance is controlled.

## 6. Knowledge-level consequence

The relevant operation is not simply `a periodical publicized a remarkable slide`. The periodical gives textual form to the retrieval procedure: number/line/order/key. It makes visible how classification has been built into the material arrangement of a preparation.

This is an unusually clean junction of the project's two levels:
- material address: the diatom occupies a specific position within an ordered preparation;
- documentary address: the accompanying key translates that position into a name;
- printed description: the 1868 periodical makes the coupled reference procedure legible to readers who do not possess the object.

The periodical is therefore describing a knowledge object whose claim to usefulness depends on addressability.

## 7. Evidence guards

- Do not substitute the 1868 *Science-Gossip* count of about 400 diatoms / 370 species with later counts from other Möller Typenplatten; individual editions/examples vary.
- Do not infer that all Möller arranged slides use identical square/line geometry.
- Do not identify the Harvard 1868 no. 42 as the Quekett exhibition object without provenance.
- Do not convert `types of the genera and subdivisions` into nomenclatural type specimens in the modern Code sense. `Typen Platte` here is a comparative/type-form reference collection.
- Keep the La Plata acquisition/survival evidence separate from the 1868 exhibition unless a documentary provenance bridge is found.
